# Career Application Assistant documentation

English | [简体中文](README.zh-CN.md)

Use these guides according to what you are doing:

- [Getting started](getting-started.md): install dependencies, initialize the local overlay, run diagnostics, and start standard or demo mode.
- [Application workflow](application-workflow.md): prepare a form, stop before final submission, record the review state, and update the timeline safely.
- [Mail ingestion](mail-ingestion.md): connect supported providers, understand incremental reads, and review structured candidates.
- [Security and privacy](security-and-privacy.md): data boundaries, credential storage, network limits, and public-release controls.
- [Development and API reference](development.md): repository layout, API surface, tests, CI, and troubleshooting.

Project-level policies are in [AGENTS.md](../AGENTS.md), [CONTRIBUTING.md](../CONTRIBUTING.md), and [SECURITY.md](../SECURITY.md). Third-party components are listed in [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md).
